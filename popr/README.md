# POPR: Polynomial OPtimization for Robotics

## Credits

In making this toolbox we were inspired by the nice work of the creators of [PEPit](https://github.com/PerformanceEstimation/PEPit?tab=readme-ov-file).

## Disclaimer 

This toolbox is currently in development. We will aim to keep things as reproducible as possible, in particular ensuring backwards compatibility with the [constraint_learning](https://github.com/utiasASRL/constraint_learning.git) where this code originated from. However, we found that the noble goal of ensuring perfect reprodubility is somewhat at odds with designing a maintainable and versatile toolbox. Ensuring reproducibility of the initial results was found to slow us down in improving the performance and the usability of the toolbox.
